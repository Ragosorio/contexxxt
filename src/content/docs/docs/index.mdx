## La idea central

Más contexto no garantiza una mejor respuesta. contexxxt optimiza cuatro decisiones:

| Principio | Decide |
| --- | --- |
| Relevancia | qué entra |
| Recencia | qué deja de aplicar |
| Recuperación | cuándo se trae |
| Ranking | dónde se coloca |

Todo lo demás —skills, memorias, proyectos, handoffs y herramientas— existe para hacer esas decisiones visibles y mantenibles.

## Qué produce

```text
.contextos/
├── manifest.json
├── core/
│   ├── IDENTITY.md
│   ├── PRIVACY.md
│   └── MEMORY_POLICY.md
├── spaces/
├── projects/
├── generated/
└── patches/
```

Los archivos del núcleo pertenecen al usuario. Los adaptadores se derivan y pueden regenerarse. Si modificas un archivo generado, contexxxt crea una propuesta en vez de reemplazarlo.

:::tip[Paquete oficial]
El proyecto se distribuye como `contexxxt`. Ejecútalo sin instalación global con `npx contexxxt` o `pnpm dlx contexxxt`.
:::
