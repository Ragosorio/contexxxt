# Contribuir

Gracias por ayudar a mejorar contexxxt.

1. Abre un issue que describa la falla de contexto o el flujo que quieres cubrir.
2. No agregues una restricción sin un caso reproducible donde haga falta.
3. Mantén el núcleo neutral: los dominios personales son ejemplos, no defaults.
4. Añade o actualiza una evaluación para todo cambio de routing, memoria, seguridad o generación.
5. Ejecuta `pnpm check` antes de enviar un pull request.

No incluyas transcripts reales, memorias, rutas locales, nombres de clientes, credenciales ni capturas privadas en issues o fixtures.
