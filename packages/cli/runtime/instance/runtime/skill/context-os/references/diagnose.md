# Diagnose context failure

Do not assume the model is the cause.

| Symptom | Hypothesis | First test |
| --- | --- | --- |
| false fact repeats | poisoning | clean session from verified sources |
| no new alternatives | distraction | compact and restart |
| wrong tool | confusion | reduce catalogue and clarify descriptions |
| inconsistent rules | clash | find duplicate/conflicting instructions |
| initial rule disappears | normal degradation | move it to short durable guidance |

Freeze the failing question and visible configuration. Find the first turn that supports the hypothesis. Offer one alternative explanation. Change one mitigation at a time.

Adding a correction does not delete the false premise. For poisoning, prefer a clean context.
