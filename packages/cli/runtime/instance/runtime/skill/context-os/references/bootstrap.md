# Bootstrap

## Existing project

1. Audit in read-only mode before writing.
2. Inventory instructions, skills, agents, state, decisions and sources.
3. Classify each source: accepted, proposed, historical, generated or unknown.
4. Identify account and sensitivity boundaries.
5. Propose the smallest `.contextos/` instance.
6. Preserve existing `AGENTS.md`, `CLAUDE.md` and local settings; create patches for integration.

## New project

1. Create the neutral core with empty memory.
2. Ask for purpose, authority and privacy before domains or tools.
3. Create one space. Add another only when purpose, account, sensitivity or sources differ.
4. Create a project contract and verifiable done conditions.
5. Generate one provider adapter and test discovery before adding more.

## Missing input

Ask at most three high-value questions. Prefer a reversible default when safe. Never create personal facts to fill a template.
