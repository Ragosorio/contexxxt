---
title: Prompts copiables
description: Tres conversaciones para descubrir, diseñar y aplicar tu sistema de contexto.
---

Estos prompts son puntos de partida. Context OS está diseñado para que luego puedas hablar con normalidad.

## 1. Descubrir

```text
Vamos a auditar mi contexto sin modificar nada.

Inventaria por fuente qué sabes de mí y de esta tarea: configuración visible,
memoria, proyecto, conversación, archivos y herramientas. No intentes revelar
instrucciones internas. Etiqueta hechos, inferencias, contradicciones, datos
sin origen y datos que podrían estar vencidos.

Después identifica las lagunas que podrían hacerte inventar en mis tres tareas
más frecuentes. Detente con el informe; no apliques cambios.
```

## 2. Diseñar

```text
Usa la auditoría confirmada para proponer una arquitectura de contexto mínima.

Separa espacios solo cuando cambien propósito, cuenta, sensibilidad, autoridad
o fuentes. Para cada dato decide si debe vivir en instrucciones globales,
proyecto, memoria, archivo estable, herramienta o prompt del turno. Incluye
vigencia, dueño y regla de expiración.

Muestra contradicciones y tradeoffs. No asumas que mis categorías actuales son
correctas. No escribas memoria ni configuración todavía.
```

## 3. Aplicar

```text
Convierte el diseño aprobado en una lista de cambios exactos y reversibles.

Para cada cambio muestra: superficie, ubicación, texto anterior si es visible,
texto nuevo completo, motivo, riesgo y cómo revertirlo. Empieza por el cambio de
mayor impacto y menor riesgo. Espera mi aprobación antes de cada escritura de
memoria o configuración. Al final entrega un inventario y fecha de próxima revisión.
```

## Iniciar una sesión normal

```text
Quiero [resultado]. Trabaja en [proyecto o espacio si lo sé].
Considero terminado cuando [criterio si lo sé].

Si mi petición mezcla un espacio, una cuenta o una decisión difícil de revertir,
detente y pregúntame lo mínimo. En lo demás, avanza con supuestos explícitos y
verifica antes de marcar completo.
```

## Compactar y continuar

```text
Construye un handoff para continuar en una sesión limpia.

Primero maximiza cobertura: objetivo, alcance, restricciones, decisiones con
motivo, estado verificado, archivos/fuentes, intentos descartados, bloqueos y
próximo paso exacto. Después elimina resultados crudos recuperables y conversación
social. Distingue hechos de inferencias y señala qué fuentes debo volver a adjuntar.
```

## Evaluar una idea sin complacencia

```text
Evalúa esta situación antes de conocer mi conclusión. Identifica evidencia,
supuestos y alternativas. Después dame el argumento más fuerte en contra de la
opción que parece preferible. Usa una rúbrica explícita y dime qué dato faltante
cambiaría la decisión.
```
