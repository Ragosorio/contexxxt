# Memory

Memory persists only after explicit approval.

## Proposal

Separate claim, evidence, counterevidence and inference. Explain which future recommendation changes if the claim is true. Propose scope, source, confidence, sensitivity, allowed surfaces and review date.

Use `candidate` when evidence is incomplete. `verified_at` may be null.

## Confirmation

Show the exact text. Confirm account and surface. Persist only after the user approves that text.

## Review

Classify each entry as confirmed, needs review, superseded, expired, rejected or never true. Do not leave the old and new claims simultaneously active.

Never store secrets, third-party personal data, brainstorming, volatile figures or organizational context on a personal surface.
