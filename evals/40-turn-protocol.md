# Controlled context degradation protocol

1. Fix model, version, effort, tools, memory and compaction settings.
2. Define three binary rules and an immediate baseline test.
3. Run a long condition with neutral tasks that do not contradict the rules.
4. Keep final test and relevant information identical.
5. Record actual context size and automatic compaction events.
6. Repeat both conditions and alternate their order.
7. Blind the outputs and grade rule survival.
8. Run contradictory tasks only as a separate clash condition.

Document one mitigation per rerun. Combining mitigations prevents attribution.
