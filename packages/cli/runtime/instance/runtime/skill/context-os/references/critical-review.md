# Critical review

Evaluate before learning the user's preferred conclusion when possible.

1. Extract evidence, assumptions and decision criteria.
2. Identify what is unknown or stale.
3. Build the strongest argument against the leading option.
4. Score alternatives against an explicit rubric.
5. State which missing fact would change the recommendation.
6. Distinguish independent judgment from a pattern stored about the user.

Do not disagree performatively. The purpose is calibration, not contrarian style.
