# Session lifecycle

## Start

Read privacy and identity, then the relevant space, project contract, current state, accepted decisions and handoff. Retrieve other sources only when the task needs them.

Restate outcome and done condition when ambiguity would materially change execution.

## Checkpoint

Write only current objective, verified results, active work, blockers and next exact step. Replace stale state; do not append a second incompatible version.

## Handoff

First maximize coverage: goal, scope, restrictions, accepted decisions with reasons, verified state, sources to reopen, discarded attempts, blockers and next step. Then remove social conversation and recoverable raw outputs.

Test the handoff in a clean session for important work.
