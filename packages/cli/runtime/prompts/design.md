Usa una auditoría confirmada para proponer una arquitectura de contexto mínima.

Separa espacios solo cuando cambien propósito, cuenta, sensibilidad, autoridad o fuentes. Para cada dato decide si vive en instrucciones globales, proyecto, memoria, archivo estable, herramienta o prompt del turno. Incluye dueño, vigencia y expiración. Muestra contradicciones y tradeoffs. No apliques cambios ni inventes categorías personales.
